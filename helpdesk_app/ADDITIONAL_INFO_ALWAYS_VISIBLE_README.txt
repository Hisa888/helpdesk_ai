追加情報フォーム 常時表示 修正

変更内容:
- 質問後に回答が出た場合でも、画面下に「追加情報を記録（任意）」を必ず表示します。
- FAQ回答、社内ドキュメントRAG回答、候補表示、該当なし、補足確認のいずれでも表示対象にしました。
- 追加情報を保存すると、既存の nohit ログ形式に追記されます。
- 既存機能は削除していません。

主な修正ファイル:
- helpdesk_app/modules/query_flow_runtime.py

確認方法:
1. streamlit を起動
   python -m streamlit run app.py
2. 任意の質問を入力
3. 回答が表示された後、画面下に「追加情報を記録（任意）」が表示されることを確認
