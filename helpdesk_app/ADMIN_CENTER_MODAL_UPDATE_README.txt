# 管理者メニュー中央ポップアップ化 修正メモ

## 対応内容

管理者モード内のボタンを押した後に表示されるポップアップを、ブラウザ画面の縦横中央に表示される疑似モーダル形式へ変更しました。

## 主な変更ファイル

- helpdesk_app/modules/admin_popup.py

## 変更ポイント

- st.popover 方式をやめ、管理者メニュー共通部品側で「ボタン → 中央モーダル表示」に変更
- モーダル背景に半透明オーバーレイを追加
- モーダル本体を画面中央に配置
- モーダル高さがブラウザを超える場合は、モーダル内で縦スクロール
- 右上に「閉じる」ボタンを追加
- 入れ子の詳細表示は、二重ポップアップにせず枠付きカード表示のまま維持

## 注意

この修正は Streamlit の st.container(key=...) を使います。
古い Streamlit では中央表示にならない場合があるため、その場合は Streamlit を新しい版へ更新してください。
