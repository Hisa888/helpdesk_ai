# 管理者モーダル 外側クリックで閉じる修正

## 修正内容
- 管理者モード内の中央ポップアップで「閉じる」ボタンは表示しない。
- ポップアップ外の暗い背景部分をクリックすると閉じるように修正。
- Escキーでも閉じる。
- CSSの透明背景ボタンだけではクリックを拾えない環境があったため、補助JSでカード外クリックを検知して閉じる方式を追加。
- 管理メニューの中身は、対象ボタンを押した時だけ描画する構造を維持。

## 主な変更ファイル
- helpdesk_app/modules/admin_popup.py

## 確認ポイント
1. 管理者モードで任意の管理ボタンを押す。
2. 中央にポップアップが開く。
3. 白いカード外の暗い背景をクリックする。
4. ポップアップが閉じる。
5. 白いカード内をクリックしても閉じない。
