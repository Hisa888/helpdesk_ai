# 管理者モード：アコーディオン → ポップアップボタン化 修正

## 修正内容
管理者モード内で使っていた st.expander のアコーディオン表示を、Streamlit 標準の st.popover を使った「ボタンを押すとポップアップ表示」に変更しました。

## 追加ファイル
- helpdesk_app/modules/admin_popup.py
  - admin_popover() を追加
  - Streamlit が st.popover に対応している場合はポップアップボタン表示
  - 古い Streamlit 環境では画面が壊れないように暫定的に expander へフォールバック
  - popover の入れ子でエラーにならないよう、ポップアップ内の詳細セクションは枠付きカード表示

## 変更対象
- 管理ダッシュボード
- 7日間の問い合わせ件数推移
- AI自動対応率の推移
- 削減時間の累計
- 直近7日ログ
- ログ閲覧 / 一括ダウンロード
- FAQ自動生成（該当なしログ → FAQ案）
- 社内ドキュメントRAG
- マニュアル → FAQ自動生成
- FAQ管理
- 管理者向け資料（PDF/PPT）
- 効果レポート（PDF）
- 検索精度設定
- LLM切替設定
- UI配色設定
- UIレイアウト設定

## 変更していないもの
通常ユーザー画面側の以下は管理者モードではないため、そのまま残しています。
- 回答の根拠を見る
- 追加情報を記録
- 問い合わせスレッドのサイドバー表示

## 確認ポイント
1. 管理者ログイン後、各管理メニューがアコーディオンではなくボタン表示になること
2. ボタンを押すとポップアップ内に各管理機能が表示されること
3. FAQ Excel ダウンロード / アップロードが従来通り動くこと
4. 社内ドキュメントRAGのアップロード・削除が従来通り動くこと
5. 検索精度設定・UI設定の保存が従来通り動くこと

## 注意
Streamlit が古い場合は st.popover が使えないため、ポップアップではなく従来の折りたたみ表示になります。
その場合は Streamlit を 1.32 以上へ更新してください。
