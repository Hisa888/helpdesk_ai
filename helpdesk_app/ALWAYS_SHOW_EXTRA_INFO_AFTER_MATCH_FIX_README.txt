# 該当あり回答後の「追加情報を記録（任意）」再表示修正

## 修正内容

FAQ回答・社内ドキュメントRAG回答・候補選択後など、該当ありの場合でも画面下に「追加情報を記録（任意）」欄が表示されるように修正しました。

## 原因

直近のExcel RAG回答精度修正の中で、追加情報フォームの表示条件が `pending_nohit_active` に強く依存していました。
そのため、該当なしや候補表示ではフォームが出る一方、通常の該当あり回答では表示されないケースがありました。

## 対応

- 回答本文がある場合は、該当あり/該当なしに関係なく `pending_nohit_active=True` を設定
- チャット履歴の最後に assistant 回答がある場合もフォームを表示
- 保存時は直近のユーザー質問に紐づくように `pending_nohit.question` を設定
- 既存のFAQ/RAG/Excel判定ロジックは削除していません

## 確認例

1. FAQに該当する質問を入力
2. 回答が表示される
3. 回答の根拠を見るの下、または入力欄の上に「追加情報を記録（任意）」が閉じた状態で表示される
4. 社内ドキュメントRAG回答でも同様に表示される
