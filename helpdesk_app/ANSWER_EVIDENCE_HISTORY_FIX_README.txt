# 回答の根拠表示 修正

## 修正内容
回答は正しく表示されているのに、回答履歴の「回答の根拠を見る」で
「該当なし（スコアが低いため問い合わせ誘導）」と出る問題を修正しました。

## 原因
検索直後は `used_hits` を持っていましたが、Streamlit の再描画後に使う
`st.session_state.messages` へ `used_hits / best_score / doc_hits` などの
根拠情報を保存していませんでした。
そのため、履歴再描画時に根拠が空と判断されていました。

## 対応
- assistant メッセージに検索根拠メタ情報を保存
- 履歴再描画時に used_hits が空という理由だけで nohit 扱いしないよう修正
- 既存のFAQ検索高速化処理は維持

## 確認方法
1. FAQに存在する質問を入力
2. 回答が表示される
3. 「回答の根拠を見る」を開く
4. FAQ一致度、Q、A が表示されることを確認
