# 申請書・書式探し回答優先修正

## 修正内容

「顧客の領域作成の申請書はどれですか？」のような、申請書・書式を探している質問では、Excel行の判定列（○ / × / －）よりも、申請書名・書式名・ファイル名を優先して回答するように修正しました。

## 改善前

- 正しい資料・行は拾えている
- しかし回答が「資料上の判定は○です」になる
- ユーザーが知りたい「どの申請書か」が前面に出ない

## 改善後

申請書・書式探しの質問では、以下のような回答を優先します。

- 顧客の領域作成は「顧客指定システム利用申請」に該当する可能性が高い
- 使用する申請書は「システム作業申請書_責任者承認まで.xlsx」
- 参照元として該当資料・シート・行を表示

## 対象例

- 顧客の領域作成の申請書はどれですか？
- 顧客環境作成の書式はどれですか？
- 顧客指定システム利用申請の申請書は？
- どの申請書を使えばいいですか？

## 実装ポイント

- RAG回答生成時に、質問意図が form の場合は Excel判定回答より先に申請書回答を生成
- Excelセル内のファイルサーバーフルパスから、申請書ファイル名だけを抽出
- 「システム作業申請書」「書式3」「責任者承認」などを優先候補として扱う
