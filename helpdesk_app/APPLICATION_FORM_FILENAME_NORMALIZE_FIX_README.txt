# 申請書ファイル名の正規化修正

「顧客の領域作成の申請書はどれですか？」などの申請書・書式探し回答で、
ファイルサーバー上のフォルダ名や状態ラベルが回答に混ざらないよう修正しました。

## 修正内容

- `【試運転中】`、`[最新版]` などの状態ラベルを申請書名から除去
- `\\svf1001\...` のようなファイルサーバーパスは、末尾のファイル名だけを表示
- 「説明.xlsx」「一覧.xlsx」「対応表.xlsx」は参照資料として扱い、使用申請書として出さない
- 回答欄には実際に使用する申請書名だけを表示

## 期待回答例

質問:

顧客の領域作成の申請書はどれですか？

回答:

使用する申請書は「システム作業申請書_責任者承認まで.xlsx」です。

参照資料:
- 書式別システム作業申請書の説明.xlsx / sheet 項目一覧 row 12
