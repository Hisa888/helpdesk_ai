# 申請書・書式探し検索精度修正

## 修正内容
- 「顧客の領域作成の申請書はどれですか？」のような自然な言い方を、
  「顧客指定システム利用申請」「システム作業申請書」「書式3」へ寄せて検索するように修正。
- FAQ検索と社内ドキュメントRAG検索の両方に、申請書・書式探し用の言い換え補正を追加。
- 「顧客領域作成」「顧客環境作成」「顧客用領域」「顧客システム利用」なども同じ申請に寄せる。
- 申請書・書式探しの場合は、本文要約よりも申請書名・書式名・ファイル名を優先して回答。
- Microsoft 365など別カテゴリの候補へ流れにくくする補正を追加。

## 期待回答例
質問:
顧客の領域作成の申請書はどれですか？

期待回答:
顧客の領域作成は「顧客指定システム利用申請」に該当する可能性が高いです。
使用する申請書は「書式3_システム作業申請書_責任者承認まで.xlsx」です。
