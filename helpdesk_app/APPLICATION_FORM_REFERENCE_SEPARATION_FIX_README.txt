# 申請書名と参照資料名の分離修正

「顧客の領域作成の申請書はどれですか？」のような申請書・書式探しの質問で、
参照元である「書式別システム作業申請書の説明.xlsx」を、使用する申請書として誤表示しないように修正しました。

## 修正内容

- 「説明.xlsx」「一覧.xlsx」「対応表.xlsx」「台帳.xlsx」などは参照資料として扱う
- 回答欄の「使用する申請書」には、行データ内の実申請書名・書式名を優先する
- 顧客領域作成・顧客環境作成は「顧客指定システム利用申請」に寄せる
- 実申請書名が本文に明確に抽出できない場合でも、参照資料名を申請書として出さず、システム作業申請書候補を表示する

## 期待回答例

質問: 顧客の領域作成の申請書はどれですか？

回答:
- 顧客の領域作成は「顧客指定システム利用申請」に該当する可能性が高いです。
- 使用する申請書は「システム作業申請書_責任者承認まで.xlsx」です。
- 参照資料は「書式別システム作業申請書の説明.xlsx / 項目一覧 row 12」です。
