# 人が見て問いと回答が矛盾しないための判定修正

## 修正内容

- 「どの書式」「どの申請書」「何を使う」などの資料探索型質問を判定
- 資料探索型質問では ultrafast FAQ を使わず、FAQ と RAG を必ず比較
- RAG側に Excel の「書式」「申請項目」「既存システム改修」などの構造化情報がある場合は、FAQスコアが高くてもRAGを優先
- RAG検索で申請書・書式探索系のExcel行を文脈再ランキング
- 「改修」単語だけで「第1条 改廃」FAQへ飛ぶ誤回答を抑制

## 期待結果

質問: システムの改修依頼は書式のどれですか？

回答: 書式1-2 の「既存システム改修」を使用します。
