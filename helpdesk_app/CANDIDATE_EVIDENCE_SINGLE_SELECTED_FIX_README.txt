# 候補表示時の「回答の根拠」表示改善

## 修正目的

FAQ候補が3件表示される場合に、「回答の根拠」欄にも3件すべてのFAQ本文が表示され、ユーザーにとって採用回答が分かりにくい状態を修正しました。

## 修正後の動き

- 「もしかしてこれですか？」の候補表示中
  - 候補ボタンは最大3件表示
  - 「回答の根拠を見る」は表示しない

- 候補ボタンを1件選択後
  - 選択したFAQの回答を表示
  - 「回答の根拠を見る」には選択したFAQのみ表示

- 通常の自動回答 / RAG回答 / 該当なし
  - これまで通り根拠表示を維持

## 修正ファイル

- modules/query_flow_runtime.py
- modules/chat_history_panel.py

## 確認ポイント

1. 申請書系など、候補が3件出る質問を入力する
2. 候補ボタンは3件表示される
3. 候補表示中は「回答の根拠を見る」が3件分出ない
4. 候補ボタンを押す
5. 選択したFAQの回答が表示される
6. 根拠には選択したFAQのみ表示される
