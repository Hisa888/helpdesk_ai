# DOC_RAG_EXPLAIN_POLICY_OVER_EXCEL_FIX

## 修正内容

「マルウェア対策について教えてください」のような説明要求で、Excelチェックシートの「○/×判定」だけが回答される問題を修正しました。

## 主な対応

- RAG検索候補を多めに取得し、TF-IDFと意味検索の候補を統合
- 「教えてください」「について」「とは」などの説明要求では、Excel判定行よりWord/PDFの条文・本文を優先
- Excelチェックシートの「○」「講じていますか」「判定」だけの行は、説明要求ではスコアを下げる
- 規程・マニュアル本文から箇条書きの詳細を抽出して回答する処理を優先
- 「ありますか」系やExcelチェックリストの判定回答ロジックは維持

## 期待例

質問:
マルウェア対策について教えてください。

期待回答:
情報システム管理規程案.docx の第29条「マルウェア対策」から、
マルウェア対策ソフト導入、定義ファイル自動更新、セキュリティパッチ適用、添付ファイル削除、感染疑い時のネットワーク切断・報告などを回答します。
