# Doc RAG flexible policy/rule answer fix

## 修正目的
「パスワードのルールはありますか？」のような質問で、FAQの「パスワード再設定」回答ではなく、社内規程・マニュアル内の該当条文を優先して回答するための修正です。

## 主な修正
- Word(docx)の規程文書を「第◯条」単位で分割してRAG化
- 「パスワード + ルール/基準/要件/何桁/文字数/管理」系の質問はFAQより社内資料RAGを優先
- 「パスワード忘れ/再設定/ロック解除」などの操作質問は従来どおりFAQを優先
- 規程・基準・ルール系の質問では、該当条文から箇条書きで要点抽出
- 例: 第10条「個人IDとパスワードの管理」から、7桁以上、英数字組み合わせ、個人情報不使用、推測されやすいパスワード禁止等を回答に出す

## 反映後に必要な操作
既存のRAG索引は古いチャンク構造のため、以下を実施してください。

1. Streamlitを再起動
2. 管理者画面で「ドキュメントRAGを初期化」
3. 情報システム管理規程案.docx を再アップロード
4. 「この内容でRAGへ反映」
