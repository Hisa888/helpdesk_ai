# DOC RAG intent-aware answer fix

## 修正内容

社内ドキュメントRAGの回答制御を、単純なキーワード一致から「質問意図別」に改善しました。

### 対応した問題

- 「36協定について教えて下さい」のような説明要求で、申請書の「下記1から17の項目を記入してください」が回答になってしまう問題を抑止
- 「〇〇とは」「〇〇について教えて」では、定義・概要・目的・説明文を優先
- 「申請方法」「入力方法」「記入方法」では、手順・入力案内・申請書を優先
- 「ありますか」「できますか」では、可否・判定・条件を優先
- 「期限」「担当者」「様式」なども質問意図に応じて根拠を優先

### 安全制御

説明要求に対して、社内資料内に定義・概要が見つからず、申請書の入力案内しか見つからない場合は、無理に説明として断定せず、以下のように回答します。

> 社内資料内には、この用語の詳しい定義・概要説明は見つかりませんでした。
> ただし、関連する申請・記入案内として以下の記載が見つかりました。

### 既存機能の維持

- Excelチェックシートの ○ / × / － 判定優先ロジックは維持
- 複数ドキュメントRAG管理の追加・同名差し替え・個別削除ロジックも維持
- FAQ回答、該当なし、追加情報記録欄の挙動は変更していません

## 確認例

- 36協定について教えて下さい
- 36協定の申請方法を教えて下さい
- 36協定の様式はありますか？
- 不正アクセス時の対応はありますか？
