# DOC RAG merge / DOCX persist fix

修正内容:
- 社内ドキュメントRAGへ資料を追加したとき、既存のDOCX/PDF/Excelが消えないように修正。
- 同名・同種のファイルをアップロードした場合だけ差し替え。
- 新規ファイルは既存RAGへ追加。
- Wiki本文は入力された場合のみ差し替え。空欄なら既存Wikiは保持。
- RAG chunks / manifest / TF-IDF index を全チャンクで再生成し、古いindex不整合を防止。
- DOCXについて、抽出・保存を同じbytesから行うようにして、取込途中で読み取り位置がずれる問題を防止。

確認ポイント:
1. 情報システム管理規程案.docx をアップロード
2. RAG一覧に DOCX が表示されること
3. 追加で PDF / Excel をアップロードしても、DOCX が一覧から消えないこと
4. 「システム権限者はどのような事を行いますか？」で第6条が根拠として上位に出ること
