# 社内ドキュメントRAG 複数資料保持修正

## 修正内容

「この内容でRAGへ反映」を押すたびに、既存のドキュメントRAGデータが上書きされ、最後にアップロードした1件だけが管理一覧に表示される問題を修正しました。

## 変更点

- RAG反映時に既存の chunks.json / manifest.json を読み込むように変更
- 新しくアップロードした資料は既存資料へ追加
- 同名ファイルをアップロードした場合のみ、そのファイルを差し替え
- 既存の別ファイルは削除せず保持
- 社内ドキュメントRAG管理に複数ファイルが一覧表示されるように修正
- 各ファイルのチャンク数を、現在のchunks.jsonから再計算
- 削除ボタンは対象ファイルだけを削除する既存仕様を維持
- Wiki本文は入力された場合のみ差し替え、空欄の場合は既存Wikiを保持

## 確認方法

1. 管理者でログイン
2. 社内ドキュメントRAGに PDF / DOCX / XLSX などを1件アップロードして反映
3. 別ファイルを追加でアップロードして反映
4. 社内ドキュメントRAG管理に、1件目と2件目の両方が表示されることを確認

## 注意

過去に「ドキュメントRAGを初期化」を押して消えた資料は、もう一度アップロードしてください。
今回の修正後は、追加アップロードしても既存資料は残ります。
