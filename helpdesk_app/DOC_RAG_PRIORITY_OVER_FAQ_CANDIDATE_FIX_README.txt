# 社内ドキュメントRAG優先制御 修正

## 修正目的
「36協定について教えてください」のような社内制度・規程・労務系の質問に対して、
FAQ側の Microsoft 365 など無関係な候補が先に表示される問題を修正しました。

## 修正内容
- 36協定、就業規則、社内規程、法令、契約、労務、有給休暇などの質問を「業務資料優先質問」として判定
- 業務資料優先質問では、FAQ候補より先に社内ドキュメントRAGを検索
- 社内資料に該当がある場合は、FAQ候補ではなくRAG回答を表示
- 社内資料に明確な該当がない場合も、カテゴリ違いのFAQ候補を出さず、安全な「該当なし」回答にする
- 検索精度設定に「業務資料優先しきい値」を追加

## 期待例
質問: 36協定について教えてください

期待動作:
- Microsoft 365 FAQ候補を表示しない
- 社内資料RAGを優先
- 資料内に定義・概要があればそれを回答
- 定義がなく申請書の記入案内しかない場合は、その旨を明示して関連記載として表示
