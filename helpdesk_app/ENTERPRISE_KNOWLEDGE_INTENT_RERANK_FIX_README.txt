# 企業ナレッジ検索 intent rerank 修正

## 修正内容
- 「何を行う」「役割」「責務」「とは」「内容」などの説明系質問では、FAQの高スコア単語一致だけで自動回答しないようにしました。
- 説明系質問では、社内ドキュメントRAGを必ず比較します。
- DOCX/PDF/TXT/Wiki の見出し・場所・本文が質問主語に合う場合、FAQの書式系回答よりRAGを優先します。
- 例：「情報システム責任者はなにを行いますか？」では、書式FAQではなく「第5条 情報システム責任者」の本文を優先するようにしました。

## 重要
- 特定の「情報システム責任者」だけに固定したハードコーディングではありません。
- 説明系質問 + 文書見出し/本文の一致で判断する汎用的な企業ナレッジ検索ロジックです。

## 確認手順
1. 管理画面で `情報システム管理規程案.docx` をアップロードします。
2. 社内ドキュメントRAG一覧に DOCX が表示されることを確認します。
3. 「情報システム責任者はなにを行いますか？」で確認します。
4. FAQの書式回答ではなく、DOCXの第5条の責務が回答されることを確認します。
