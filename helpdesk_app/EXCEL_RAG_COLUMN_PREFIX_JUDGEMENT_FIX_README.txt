# Excel RAG 判定列優先・列名混入修正

## 修正内容
- 旧チャンクに残っていた `F: ...` / `AF: ○` のようなExcel列名を回答生成時に除去。
- `AF: ○` のような形式でも判定「○」として正しく認識。
- 「ありますか？」系の質問では、判定列が○なら「はい、あります。判定は『○』です。」を回答。
- 右端の `システム？` は備考扱いにし、回答・該当項目に出さない。

## 対象例
質問: 不正アクセスがあった場合の復旧の対策はありますか？
期待回答: はい、あります。判定は「○」です。
