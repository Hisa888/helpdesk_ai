# Excel RAG 判定結果復元・最終修正

## 修正内容

Excelチェックシート型資料で、該当行は正しく検索できているのに、回答欄に「○」が出ず、F列の項目名だけが回答として表示される問題を修正しました。

## 原因

過去バージョンで作成されたRAGチャンクでは、正規化処理により Excel の判定セル（例: `AF: ○`）がチャンク本文から欠落する場合がありました。
その場合、検索結果は `法令順守体制CS row 149` を正しく指していても、回答生成側では判定「○」を復元できず、項目名を回答として表示していました。

## 対応

- Excel回答時、RAGチャンク本文だけでなく、保存済みの元Excelファイルを再読込します。
- 検索ヒットの `sheet xxx row n` から対象シート・行を特定します。
- 対象行の `○ / × / －` 判定セルを元Excelから直接復元します。
- `システム?` など右端の分類・備考は回答本文に出さず、備考扱いにします。
- 「ありますか？」系の質問では、判定が `○` の場合に `はい、あります。判定は「○」です。` と回答します。
- 旧チャンクでも、元Excelが保存されていれば再アップロードなしでも判定を復元できます。

## 期待される回答例

質問: 不正アクセス時の対応はありますか？

回答:

```
社内資料から該当箇所が見つかりました。

【回答】
はい、あります。判定は「○」です。

【該当項目】
不正アクセスの発生に備えた対応・復旧手続の整備

【補足・根拠】
「障害発生時の技術的対応・復旧手続の整備として、以下の措置を講じていますか 【指針5-4、5-4-2】」の中で、
「不正アクセスの発生に備えた対応・復旧手続の整備」が「○」になっています。

【参照元】
- TEST.xlsx / sheet 法令順守体制CS row 149
```

## 反映手順

1. Streamlit を停止します。
2. このZIPの内容で既存フォルダを置き換えます。
3. `streamlit run app.py` で起動します。
4. 念のため、管理者画面から「ドキュメントRAGを初期化」→ `TEST.xlsx` を再アップロード → 「この内容でRAGへ反映」を実行してください。
