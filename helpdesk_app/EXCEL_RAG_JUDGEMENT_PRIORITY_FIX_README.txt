# Excel RAG 判定列優先修正

## 修正目的
Excelチェックシート型の社内資料で、回答として出すべき「○ / 〇 / × / －」ではなく、
F列などの項目名や右側の備考（例: システム？）が回答本文に出てしまう問題を修正しました。

## 主な修正内容
- Excel取り込み時の正規化で「○」を削除しないように修正
  - 以前はPDFノイズ除去用の処理で「○」が消えるケースがありました。
- Excel行に「判定結果」と「回答」を明示的に保持
  - 判定列の「○ / 〇 / × / －」を回答として最優先します。
- 右側の列は「補足」として扱う
  - 「システム？」のような短い分類メモは回答画面では表示しません。
- 旧チャンク互換も修正
  - `F: xxx / AF: ○` のような旧形式でも `F:` が回答に混ざらないようにしました。
- Excel検索の再ランキングを追加
  - 「不正アクセスにあった場合の復旧の手順はありますか？」では、
    「不正アクセスの監視機能」行ではなく、
    「不正アクセスの発生に備えた対応・復旧手続の整備」行を優先します。

## 確認例
- 質問: 不正アクセスにあった場合の復旧の手順はありますか？
  - 参照元: TEST.xlsx / 法令順守体制CS / row 149
  - 回答: ○

- 質問: 入室制限はどのようになってますか？
  - 参照元: TEST.xlsx / 管理体制CS / row 38
  - 回答: ×
  - 補足として入退室管理の詳細説明を表示

## 反映後の注意
既に取り込んだRAGデータが残っている場合は、管理者画面で以下を実施してください。

1. ドキュメントRAGを初期化
2. TEST.xlsx を再アップロード
3. 「この内容でRAGへ反映」
4. Streamlitを再起動
