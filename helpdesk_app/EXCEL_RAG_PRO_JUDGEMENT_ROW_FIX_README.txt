# Excel RAG 判定列・親子設問プロ修正

## 修正目的
ExcelチェックシートをRAGに取り込んだ際、右端の分類欄（例:「システム？」）や項目名が回答として表示され、
本来の判定「○ / × / －」が回答に反映されない問題を修正しました。

## 主な修正
- Excelの「○」「〇」「◎」「△」を正規化処理で消さないように保護
- Excel行内の判定列「○ / × / －」を回答の最優先情報として扱う
- 「ありますか？」「対策はありますか？」などの質問では、判定「○」を「はい、あります。判定は『○』です。」と回答
- 右端の短い分類・備考（例:「システム？」）を回答・該当項目にしない
- 親設問行（例:「障害発生時の技術的対応・復旧手続の整備」）を直下の①②③明細行に付与
- ただし、通常のNo行（例: 管理体制CS row 38 / No.23）には別セクションの親設問が混ざらないよう制御
- 「不正アクセス」「復旧」「対策」「リカバリ」系の検索語補完を追加

## 確認例
質問: 不正アクセスがあった場合の復旧の対策はありますか？
期待回答: はい、あります。判定は「○」です。
参照元: TEST.xlsx / 法令順守体制CS / row 149

質問: 入室制限はどのようになってますか？
期待回答: 管理体制CS row 38 の「×」と補足理由を表示
