# Excel RAG 行単位チャンク修正

## 修正内容

「入室制限はどのようになってますか？」のような質問で、TEST.xlsx の正しい行ではなく、近くの「廃棄」行などが回答に混ざる問題を修正しました。

## 原因

従来は Excel を「1シート単位の本文」として取り込み、その後 700文字前後のチャンクに分割していました。
そのため、チェックシートの隣接行が同じチャンクに入り、回答時に複数行の内容が混ざることがありました。

## 対応

- Excel（xlsx/xlsm）は「1行＝1チャンク」で取り込むように変更
- Excel行ごとに、シート名・Excel行・No・項目・確認事項・判定結果・回答/理由・元データを保持
- Excelの回答生成時は、最上位の1行だけを回答根拠に使用
- 旧形式の chunks.json が残っている場合も、検索時に row 36 / row 37 / row 38 のような行単位へ自動展開
- 「入室制限」→「入退室管理」「入室可能者」「セキュリティカード」「監視カメラ」などの検索語補完を追加
- Excel行が採用された場合は、LLMで複数行を混ぜず、該当行から決定的に回答を整形

## 期待される回答例

質問:
入室制限はどのようになってますか？

回答:
社内資料から該当箇所が見つかりました。

【該当項目】
入退室管理

【回答】
機密情報を保存するサーバやシステム等の設置場所への入退室に関しては、管理台帳・監視カメラ等で管理している。また入室者に関しては、セキュリティカードにより入室を制限し、持ち込む機器に関しても、許可されている機器以外の持ち込みを禁止し、その持ち込みを監視カメラで常時監視しているが、社員各自の相互監視が中心となり、定期的な確認までは実施していない。
判定結果は「×」です。

【参照元】
- TEST.xlsx / sheet 管理体制CS row 38
