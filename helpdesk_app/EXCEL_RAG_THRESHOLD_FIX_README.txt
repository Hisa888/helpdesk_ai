Excel RAG回答なし修正

現象:
- TEST.xlsx の管理体制CS row 38 に「入退室管理」の正しい行があるにもかかわらず、
  「入室制限はどのようになってますか？」で「FAQに該当がありませんでした」と表示される。

原因:
- Excel行検索の一致度は約0.33程度になるが、管理画面のDoc採用しきい値初期値が0.55のため、
  正しいExcel行が見つかっていてもDoc回答として採用されなかった。

修正:
- Excel/xlsm のRAGヒットには専用の「Excel行採用しきい値」を追加。初期値は0.18。
- PDF/Wordなど通常Docは従来のDoc採用しきい値を維持。
- 検索精度設定画面に「Excel行採用しきい値」を表示・保存できるように追加。
- 「入室制限」などの質問では、TEST.xlsx / 管理体制CS / row 38 / 入退室管理を採用できる。

確認想定:
1. 管理者でTEST.xlsxをRAGへ反映
2. 「入室制限はどのようになってますか？」と質問
3. 社内資料から回答され、参照元に TEST.xlsx / sheet 管理体制CS row 38 が表示される
