# FAQ精度改善アップデート（カテゴリ固定検索・親FAQ→子FAQ・軽量再ランキング）

## 修正対象
- helpdesk_app/modules/search_runtime.py

## 改善内容
1. カテゴリ固定検索を追加
   - 質問文から VPN / ログイン / ディスプレイ / 申請書 / システム導入 などの親カテゴリを推定します。
   - TF-IDF上位に入らない場合でも、同じ親カテゴリのFAQを候補プールへ追加します。

2. 親FAQ→子FAQの順位補正を追加
   - category / intent を親FAQ、question / keywords を子FAQとして扱います。
   - 親カテゴリと子要素の両方が一致するFAQを優先します。

3. LLM再ランキング相当の軽量補正を追加
   - 毎回LLMを呼ぶと遅くなるため、質問・意図・言い換え・カテゴリの重なりで候補順位を補正します。
   - 既存のLLM回答機能・RAG機能は削除していません。

4. 誤回答抑制
   - 個別業務語、必須キーワード、除外キーワード、安全ガードは既存のまま維持しています。
   - 「回答はあるのに該当なし」になりにくくしつつ、違うカテゴリのFAQを自動回答しにくくしています。

## 確認してほしい質問例
- VPNにつながりません
- VPNに接続できません
- ディスプレイが真っ暗です
- モニターが映らない
- パスワード忘れた
- ログインできない
- アカウントがロックされた
- 起案書の書式はありますか？
- システム導入するための申請書はどれですか？

## 注意
既存機能を消さず、検索順位の補正を追加する方式です。
管理画面の検索精度設定は従来通り使用できます。
