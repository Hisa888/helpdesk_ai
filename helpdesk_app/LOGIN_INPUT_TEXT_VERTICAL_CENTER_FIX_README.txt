# ログイン入力欄 文字位置中央寄せ修正

## 修正内容
ログイン画面の会社ID・ログインID・パスワード入力欄で、入力文字が下側にずれて見える問題を修正しました。

## 対象ファイル
- `modules/tenant_auth.py`

## 変更点
- 入力欄の高さを `56px` に統一
- `padding-top` / `padding-bottom` を 0 に調整
- `box-sizing: border-box` を追加
- Chrome / Edge で文字が下寄りに見える問題を補正
- パスワード表示切替ボタン付き入力欄も同じ高さに統一

## 確認方法
1. `streamlit run app.py` を実行
2. ログイン画面を表示
3. 会社ID・ログインID・パスワード欄に文字を入力
4. 入力文字がフィールド内の上下中央に表示されることを確認
