# ログインUI 空白カード表示 修正

## 修正内容

ログイン画面右上に表示されていた不要な白い空枠を削除しました。

## 原因

Streamlitでは、`st.markdown('<div>')` で開始したHTMLタグの中に `st.form()` などのネイティブコンポーネントを安全に入れることができません。
そのため、ログインカード用の空DIVだけが先に描画され、右上に白い空枠として表示されていました。

## 対応

- 不要な `login-card-shell` の空DIVを削除
- `st.form()` 自体をカード風にCSS装飾
- ログインタイトル・説明・入力欄・ボタン・セキュア表示を1つのカード内に整理
- HTMLタグがそのまま表示されない状態を維持
- 既存の会社IDログイン処理・管理者ログイン処理は維持

## 確認方法

1. `streamlit run app.py` を起動
2. ログイン画面を表示
3. 右上に白い空枠が出ないこと
4. 会社ID `demo` / ログインID `demo` / パスワード `demo` でログインできること
5. 管理者は 会社ID `demo` / ログインID `admin` / パスワード `password` でログインできること
