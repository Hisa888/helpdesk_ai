# スマホ版 導入相談ボタン巨大化 修正

## 修正内容
スマホ表示で右側の「📩 導入相談」固定ボタンが縦長に大きく表示される問題を修正しました。

原因は、スマホ用CSSで fixed ボタンに `top` と `bottom` が同時に効き、iPhone/Safari上でボタンが上下に引き伸ばされるケースがあったためです。

## 対応
- スマホ表示時は `.fixed-contact-button` の `top` を解除
- `bottom: 76px` の右下固定に統一
- 幅を `112px〜148px` に制限
- 高さを `42px〜46px` に制限
- 通常ボタンの幅100%化の影響を受けないように個別上書き
- PC表示の導入相談ボタンや既存機能は変更なし

## 確認ポイント
1. スマホで「導入相談」ボタンが右下付近に小さく表示されること
2. 縦長の巨大ボタンにならないこと
3. 問い合わせ入力欄が下部に表示されること
4. PC表示はこれまで通りであること
