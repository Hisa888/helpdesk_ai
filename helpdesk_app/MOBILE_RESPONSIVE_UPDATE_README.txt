# スマホ問い合わせ対応アップデート

## 変更内容
- `helpdesk_app/modules/app_bootstrap.py` に `render_mobile_responsive_css()` を追加しました。
- 画面幅 768px 以下の場合だけ、スマホ向けの表示に切り替わります。
- PC表示・既存機能・管理者メニューの処理は削除していません。

## スマホで改善される点
- 問い合わせ入力欄をスマホ下部に固定
- ボタンを押しやすい高さ・横幅に調整
- 横並びカードを縦並びに変更
- FAQ回答・根拠・カードの余白をスマホ向けに調整
- 表やログは横スクロールで確認可能
- サイドバーはスマホでは画面幅 86% に調整
- iPhoneで入力時に画面が勝手にズームしにくいよう文字サイズを調整

## 確認ポイント
1. PC表示が今まで通り崩れていないこと
2. スマホで問い合わせ入力欄が下部に表示されること
3. スマホで候補ボタン・導入相談ボタンが押しやすいこと
4. 管理者メニューの表が横スクロールできること
