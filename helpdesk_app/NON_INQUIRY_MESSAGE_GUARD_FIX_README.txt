# 雑談・お礼入力の誤RAG回答防止 修正

## 修正内容

「ありがとうございます。」などの短いお礼・挨拶・相づちが、FAQ/RAG検索に回ってしまい、
Excel内の無関係な行から回答が出てしまう問題を修正しました。

## 対応方針

- 「ありがとうございます。」「ありがとう」「助かりました」などはRAG検索しない
- 「おはようございます」「こんにちは」「了解です」なども通常会話として扱う
- 通常会話では「回答の根拠を見る」を表示しない
- 通常会話では「追加情報を記録（任意）」フォームを出さない
- 通常会話では導入相談CTAも出さない
- 「ありがとうございます。VPNがつながりません」のように、問い合わせ本文が含まれる場合は通常検索に回す

## 確認例

入力:

```text
ありがとうございます。
```

期待表示:

```text
どういたしまして。引き続き、社内IT問い合わせがあれば入力してください。
```

入力:

```text
不正アクセス時の対応はありますか？
```

期待表示:

従来どおりFAQ/RAG検索し、該当資料から回答します。
