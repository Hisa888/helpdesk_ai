# 運営者専用：会社・ライセンス管理 追加

## 追加内容
- role=owner のログインIDだけに「会社・ライセンス管理（運営者専用）」を表示します。
- 顧客側 admin/user には表示されません。
- 会社IDごとの会社名、ライセンス種別、有効期限、有効/停止、最大ユーザー数、メモを登録・更新できます。
- ライセンスDBから削除しても、会社別FAQ/RAG/ログデータは削除しません。

## 初期ownerログイン例
.streamlit/secrets.toml に以下を追加しています。

owner / owner / change_me

本番では必ずパスワードを変更してください。

## 注意
会社IDをライセンス管理に登録しても、その会社でログインするユーザーは TENANT_USERS に別途追加してください。
例:
  "abc:yamada:password:山田:admin"
