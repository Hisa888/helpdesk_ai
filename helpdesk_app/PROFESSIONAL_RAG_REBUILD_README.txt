# Professional RAG Rebuild / Answer Logic Reset

この修正では、質問後の回答ロジックを以下の方針で整理し直しました。

## 方針
- FAQ/Excel/Word/PDFを単純なスコア順で混ぜない
- 質問意図を先に判定する
- 第◯条指定は、意味検索ではなく条番号一致を最優先する
- 役割・責務・職務の質問は、見出し一致（第◯条 〇〇）を優先する
- 説明要求は、Excelチェックシートの○/×より、規程・マニュアル本文を優先する
- Excelチェックシートは「ありますか？」系の可否判定でのみ○/×を優先する
- 申請書探しは、判定ではなく申請書名・書式名を優先する

## 代表確認
- 情報システム管理規程第13条何ですか？
  → 第13条 保管場所を回答
- 取締役はどのようなことを行いますか？
  → 組織規程 第13条 取締役を回答
- マルウェア対策について教えてください。
  → 情報システム管理規程 第29条 マルウェア対策を回答
- パスワードのルールはありますか？
  → 情報システム管理規程 第10条 個人IDとパスワードの管理を回答
- 顧客の領域作成の申請書はどれですか？
  → 顧客指定システム利用申請 / システム作業申請書を回答

## 注意
既存の古いRAG索引は、PDF/Wordがページ単位・大きいチャンク単位のまま残っている可能性があります。
反映後は、管理画面で「ドキュメントRAGを初期化」して、資料を再アップロードしてください。
