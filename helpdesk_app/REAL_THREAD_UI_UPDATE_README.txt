# 本物の問い合わせスレッド管理UI 追加

## 追加内容
- 左サイドバーに「問い合わせスレッド」欄を追加
- 「＋ 新規問い合わせ」で問い合わせ単位のスレッドを作成
- 「対応中 / 完了」管理
- スレッド選択時に中央画面は該当スレッドの会話だけ表示
- スレッドごとに messages を保持
- 「やり方」「どうやる」「詳しく」「分からない」などの補足質問は、現在スレッドの主題を付与して検索

## 期待される動き
1. 「Excelが起動しない」でスレッド作成
2. 同じスレッド内で「セーフモードのやり方が分からない」と聞く
3. 検索内部では「Excelが起動しない + 補足質問」として扱う
4. 別件は「＋ 新規問い合わせ」から分ける

- modules/inquiry_thread_ui_runtime.py
- modules/main_screen_layout.py
- modules/chat_input_panel.py
- modules/chat_interaction_runtime.py
