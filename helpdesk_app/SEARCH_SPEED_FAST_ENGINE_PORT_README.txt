# 検索速度改善パッチ

## 対応内容

遅い版の機能は残したまま、検索処理のみ `helpdesk_app_20260504_サーバーUP版2` の高速検索処理へ戻しました。

主な変更:

- `modules/search_runtime.py` を高速版に差し替え
- `modules/query_flow_runtime.py` を高速版に差し替え
- 問い合わせスレッド文脈キーによる検索キャッシュ分散を廃止
- LLM再ランキング処理を検索フローから除外
- FAQ自動回答時の不要なLLM整形呼び出しを抑制
- `__pycache__` をZIPから除外

## 期待する効果

FAQ検索時に毎回重い補正・LLM再ランキング・スレッド文脈処理を走らせず、
`helpdesk_app_20260504_サーバーUP版2` に近い応答速度へ戻します。

## 残している機能

- 会社IDログイン
- 無料トライアル期限表示
- 導入相談CTA
- アコーディオン型管理画面
- FAQ/RAG管理系ファイル
