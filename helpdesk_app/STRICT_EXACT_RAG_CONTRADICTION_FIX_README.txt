# FAQ完全一致・書式/ファイル名完全一致・RAG矛盾チェック強化

## 修正内容

回答順序を以下の安全優先ロジックに寄せました。

1. FAQ質問文の完全一致を最優先で採用
2. 書式名・申請書名の直接一致をRAG候補で優先
3. ファイル名の直接一致をRAG候補で優先
4. RAGスコアは候補抽出に使い、回答前に意図別に再順位付け
5. 質問語と候補が矛盾する場合は断定回答しない

## 主な対象ファイル

- helpdesk_app/modules/query_flow_runtime.py
- helpdesk_app/modules/document_rag_runtime.py

## 顧客領域作成の誤回答対策

「顧客の領域作成の申請書はどこですか？」のような質問で、
単なる「顧客指定システム利用申請」だけを根拠に断定しないようにしました。

領域作成/環境作成/システム作業申請書/書式3/責任者承認など、
質問に近い根拠がある候補を優先します。
