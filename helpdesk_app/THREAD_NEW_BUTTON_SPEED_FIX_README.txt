# 新規問い合わせボタン 高速化修正

## 修正目的
「＋ 新規問い合わせ」ボタン押下後に約1分応答がない問題を改善しました。

## 原因
Streamlitのボタン押下だけで画面は再実行されますが、旧実装ではボタン処理内でさらに `st.rerun()` を呼んでいたため、重い初期化・FAQ読込・UI描画が二重に走る場合がありました。

## 修正内容
- 新規問い合わせ作成時の明示的な `st.rerun()` を削除
- スレッド切替・対応中/完了変更でも不要な二重再実行を削除
- 代わりに `st.toast()` で操作完了を即時通知
- 既存のFAQ検索、RAG、管理画面、スレッド文脈検索機能は削除していません

## 確認ポイント
1. 「＋ 新規問い合わせ」を押す
2. すぐに入力欄が空の新規スレッドに切り替わる
3. 既存スレッドを選択して戻れる
4. 「Excelが起動しない」→「セーフモード起動ってどうやるの？」で文脈検索が動く
