# 速度優先・UI配色修正版

対応内容:

- 問い合わせスレッド機能を画面/処理から無効化しました。
  - 左メニューの「問い合わせスレッド」を非表示
  - チャット送信時のスレッド保存/読込/カテゴリ固定処理を停止
  - 質問はそのままFAQ/RAG検索へ渡します
- 無料トライアル表示カードの文字色を固定しました。
  - 左メニュー文字色設定に引きずられず、常に見える色で表示
- UI配色設定を「保存後反映」に変更しました。
  - 色を選んだだけでは画面全体へ反映しません
  - 「UI配色を保存」押下後に再読み込みして反映します
  - 保存前に画面が薄くなったように見える混乱を減らします

既存のアコーディオンボタン版、会社IDログイン、無料トライアル期限管理は維持しています。
