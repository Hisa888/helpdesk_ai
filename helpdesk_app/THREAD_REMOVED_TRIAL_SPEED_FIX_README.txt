# 修正内容

- 無料トライアル期限が消える問題を修正しました。既存DBの期限日が空の場合、`.streamlit/secrets.toml` の `DEFAULT_TRIAL_EXPIRE_DATE` を自動補完します。
- サイドバーの無料トライアル表示を濃い文字色・固定背景色にして、左メニュー配色に影響されないようにしました。
- 問い合わせスレッド機能ファイルを削除し、検索時にスレッド系モジュールを読み込まないようにしました。
- LLM再ランキングは初期状態では無効にし、通常検索の体感速度を優先しました。必要な場合は検索精度設定で明示的に有効化してください。
- UI配色設定はフォーム化し、保存前に色選択だけで画面全体が薄くなる/再描画される挙動を抑制しました。
